# fumi-site

Fumi official website.

## Wireframes

`pyoeunji.com` を参考にサイト構造を分析し、FUMI OFFICIAL FANCLUB 用のワイヤーフレームを
[`wireframes/`](./wireframes/README.md) に作成しています。

- ASCII 図による全ページ俯瞰: [`wireframes/README.md`](./wireframes/README.md)
- 低忠実度 HTML モック:
  [Home](./wireframes/index.html) ·
  [Profile](./wireframes/profile.html) ·
  [Shop](./wireframes/shop.html) ·
  [Product](./wireframes/product.html)

ローカル確認: `python3 -m http.server 8000 --directory wireframes` → <http://localhost:8000/index.html>
