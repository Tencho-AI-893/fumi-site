# fumi-site

Fumi official website.

## Wireframes

`pyoeunji.com` を参考にサイト構造を分析し、FUMI OFFICIAL FANCLUB 用のワイヤーフレームを
[`wireframes/`](./wireframes/) に作成しました。

**👉 まずはここから見てください**: [`wireframes/guide.html`](./wireframes/guide.html)
（非エンジニア向けの解説付き目次。クリックで各ページの下書きに飛べます）

ローカルでブラウザ確認:
```
python3 -m http.server 8000 --directory wireframes
```
→ <http://localhost:8000/guide.html> を開く（紙で渡したい場合は印刷→PDF保存）
