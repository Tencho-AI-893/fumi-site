# FLEX-TENCHO SECOND BRAIN 設計書 Phase 1（Ver.1）

## 1. 一言でいうと
店長は「書いて保存」を押すだけ。AIが分類・要約し、**原文はそのまま**Notionに保存する。
失敗しても原文はPC内の金庫（SQLite）に残り、後で再送できる。

## 2. 全体の流れ
```
[入力画面(このPCだけ)] → [金庫:SQLite 原文を先に保存]
      → [機微チェック] ─引っかかる→ AIに送らない（別DB or PC内で保留。承認で解除）
      → [AI分類・要約] ─失敗→ 「失敗」印。原文は無事。再送ボタンで再開
      → [Notion保存] ─失敗→ 同上（AI結果は再利用＝AI代の二重払いなし）
      → 完了（Notionのリンクを表示）
```

## 3. 最小構成（初版で作るもの／作らないもの）
- 作る：入力画面1枚、AI分類、Notion保存、再送、重複防止、機微の分離
- 作らない（後のPhase）：検索、Evernote移行、ChatGPT連携、関連付け、PDF・画像・音声
- 外部の部品（ライブラリ）は**ゼロ**。Pythonだけで動く＝壊れにくい・秘密が漏れにくい。

## 4. Notionのデータ構造（データベース1つだけ）
| 項目 | 内容 |
|---|---|
| タイトル | AIが付ける（30字） |
| 要約 | AIの要約（※原文は上書きしない） |
| カテゴリー | 初期8分類＋「要確認」。`categories.json`で追加・変更自由 |
| タグ | 最大5個 |
| 登録日時 | 入力した時刻 |
| 元情報 | メモ/アイデア/会議メモ/URL/ブログ下書き/AI会話ログ/投資記録/業務改善 |
| 関連プロジェクト | AIが推定（無ければ空） |
| 信頼度 | 0〜1。0.6未満は「要確認」（変更可） |
| 要確認 | 自信が低い時にチェック |
| AI推定 | 「要確認」時にAIが考えた候補（断定しない） |
| 原文ハッシュ | 重複判定用の指紋 |
| ページ本文 | **原文そのまま**（長文は分割して全文保存） |

機微メモ用に、同じ形のDBをもう1つ（任意）。原文だけを保存し、AIは通さない。タイトルに本文は出さない。

## 5. セキュリティ設計
- 鍵（Notion・OpenAI）は `.env` のみ。コードに無し。`.gitignore`で`.env`と`data/`をGit対象外に。
- 入力画面は `127.0.0.1`（このPC内）限定。外部公開しない。他サイトからの勝手な送信（CSRF）と偽ホスト名（DNS rebinding）を拒否。
- ログに本文を出さない（アクセスログ無効・エラーは種類と200字までの理由のみ）。
- 機微検出（電話・メール・カード/口座らしき数字・APIキー・「パスワード」「口座番号」等のキーワード）→ **AIに送らない**。画面の「承認してAIに送る」を押した時だけ送る。「AIに送らない」チェックで手動指定も可。
- NotionのIntegrationは「内容の読み取り・挿入・更新」だけ許可し、第二の脳用ページ1つにだけ共有する（最小権限）。削除機能は**実装していない**。
- AIの出力は必ず検証。知らないカテゴリーは「要確認」。メモ内の「命令文」にAIが従わないようプロンプトで明示（データとして扱う）。
- 削除・大量変更・原文の統合は、将来も「事前承認必須」の方針。

## 6. 技術判断と未確認事項（正直ベース）
- Notion APIバージョンは既定 `2022-06-28`（長く安定している版）。新しい版(2025-09-03以降)は「データソース」という概念が入り、保存先の指定方法が変わる。`.env`の`NOTION_VERSION` / `NOTION_DATA_SOURCE_ID`で切替可能に実装済み。
- ⚠️ **この開発環境からはNotion公式ドキュメントに接続できず、最新仕様を公式で直接確認できていない。** 二次情報のみ。→ 初回の実保存テストで必ず検証する（最初の成功条件そのもの）。
- AIモデル既定 `gpt-4o-mini`（安価帯）。最新の料金・名称は契約画面で要確認。`LLM_PROVIDER=ollama`で店内ローカルAIに切替可（TENCHO-AIと同じ基盤）。

## 7. 費用の概算（ざっくり。要・最新料金確認）
- Notion：個人利用の無料プランでAPI連携は可能（容量・ブロック制限の範囲内）。
- OpenAI API：1件あたり約1,000〜2,000トークン。小型モデルなら1件 約0.1〜0.5円。**1日20件でも月 数十円〜数百円**が目安。使った分だけの従量課金（上限額をOpenAI側で設定可能）。
- Ollama切替なら通信費0（電気代のみ）。
- サーバー代：0円（ローカルPCで動かす）。
